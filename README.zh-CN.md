# Blueks代办

一个**独立的任务/需求看板**插件：自己新建待办、流转状态、按「分组」组织，组内按完成时间从新到旧排序，一眼看到每个功能最近完成了什么。每个待办都能一键生成思源文档并随时跳转过去。

> 不扫描笔记里的复选框，数据独立保存在插件自己的存储里。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 页签界面 | 待办中心直接打开在思源标签页里，不弹窗 |
| 新增待办 | 右上角「新增待办」或快捷键（默认 ⌥⌘T）打开新建弹窗 |
| 状态流转 | 待处理 → 进行中 → 已完成 / 已关闭 / 已取消，随时可重新打开 |
| 时间记录 | 完成时间、关闭时间、取消时间自动记录，卡片与详情都能看到 |
| 分组 | 左侧按功能（如「登录模块」「支付流程」）组织；分组项悬停出现 ✏️ 编辑按钮，可直接改名+换色，右键菜单还有重命名/改色/删除 |
| 排序 | 未完成的排在前面（优先级 → 截止日期 → 创建时间）；已完结的按完成/关闭/取消时间**从新到旧** |
| 标签 | 待办可打任意多个标签；左侧标签区**随分组联动**，支持**多选标签**取并集筛选 |
| 近7天汇总 | 首页顶部汇总近 7 天**已完成 + 已关闭**的待办：按天列出、带头部统计、每条显示状态标签，可折叠，条目可点击跳到详情 |
| 分页加载 | 列表每页渲染 50 条，滚动到底自动追加，上千条待办也不卡 |
| 按年归档 | 顶栏 📥 一键把**已关闭**的待办按关闭年份归档到 `archive-年.json`，主列表保持轻量 |
| 查看归档 | 筛选行「含归档」开关：归档待办重新并入列表，仍可按分组、标签、搜索查看；归档期间只读，可一键取消归档 |
| 批量操作 | 筛选行「批量」开关：勾选多条后批量设为 进行中/已完成/已关闭/已取消，或批量删除 |
| 导入历史待办 | 粘贴 markdown 清单（`- [X]` / `- [ ]` / `- [-]`）一次性导入；支持思源块引用 `((id "标题"))`，导入后点 📄 直接跳转原文档 |
| 生成思源文档 | 详情里点「新建思源文档」，按「分组 / 年月」两层目录创建，文件名即待办名称 |
| 点击跳转 | 点卡片上的 📄 图标打开对应思源文档；点卡片本身仍是选中查看详情 |
| 变更历史 | 每个任务在详情面板里有自己的完整历史；标题/描述修改也会留痕 |
| 详情面板 | 右侧可直接改标题、描述、分组、优先级、截止日期 |
| 中英双语 | 界面文案支持中文 / English |

## 文档目录设置

点顶栏 ⚙️ 打开设置：

1. 选择文档所在的**笔记本**
2. 填写**文档目录**（笔记本下的路径，默认 `待办中心`）

为待办新建文档时，目录结构为（分组、年月各占一层）：

```
笔记本 / 文档目录 / 分组 / 年月 / 待办名称
例：工作笔记 / 待办中心 / 登录模块 / 202610 / 手机号登录
```

- 文档创建成功后自动打开，并记录到该待办的变更历史
- 已关联文档的待办：卡片上出现 📄 图标，**点 📄 图标跳转**到文档（点卡片本身是选中查看详情）

## 导入历史待办

顶栏下载样式的按钮打开导入弹窗：

```
- [X] 已完成的事情        → 已完成
- [ ] 还没做的事          → 待办
- [-] 不做了的事          → 已取消
- [X] ((20260528100236-m90xogm "带块引用的待办"))  → 标题取引号内文本，并记住关联文档
```

- 可以选择导入到已有分组，或直接填一个新分组名（自动创建）
- 历史导入的条目没有准确的完成/关闭时间，因此不会进入「近7天汇总」

## 批量操作

1. 点筛选行最右侧的「批量」进入批量模式
2. 点卡片（或勾选框）选中，可「全选」当前筛选结果、「清空」
3. 一键设置状态，或批量删除（带确认）
4. 归档待办为只读，批量操作会自动跳过并提示

## 状态与时间

| 状态 | 记录的时间 |
| --- | --- |
| 待处理 | 创建时间 |
| 进行中 | 开始时间（首次进入时） |
| 已完成 | 完成时间 |
| 已关闭 | 关闭时间 |
| 已取消 | 取消时间 |

- 重新打开（回到待处理/进行中）会清空当前的完成/关闭/取消时间，历史里仍保留那一次变更记录
- 详情面板会同时列出创建、开始、完成、关闭、取消五个时间，没有的显示「—」

## 安装 / 启用

插件目录：`data/plugins/buleks-todo/`

1. 从集市安装，或把 `package.zip` 解压到 `{工作空间}/data/plugins/buleks-todo/`
2. 重启思源（或重新启用插件）
3. 顶栏出现 ✅ 图标，点击打开「Blueks代办」页签
4. 也可以在 **设置 → 键位** 里给「新建待办」命令绑定快捷键

## 数据存储

- 位置：`{工作空间}/data/storage/petal/buleks-todo/`
  - `board.json`：分组 + 待办 + 界面状态
  - `archive-YYYY.json`：按年归档的待办
- 每个任务含 `history` 数组，保存每一次变更的时间、类型、前后值
- 卸载插件不会自动删除这些文件，重装后数据还在

## 导出 / 备份

直接复制整个 `data/storage/petal/buleks-todo/` 目录即可完成备份与迁移。

## 开发

- 纯原生 JS（CommonJS），无构建步骤，改完 `index.js` 后重新加载插件即可
- 主要文件：
  - `index.js`：数据模型、状态机、列表/详情渲染、弹窗
  - `index.css`：跟随思源明暗主题的样式
  - `i18n/zh_CN.json`、`i18n/en_US.json`：文案
